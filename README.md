# PsicoLentes — central de links

Página estática e responsiva com os canais oficiais do PsicoLentes.

## Atualizar links

Abra `index.html`, procure o botão desejado e substitua o endereço no atributo `href`. Para adicionar um canal, copie um bloco `<a class="link" ...>...</a>` dentro de `<div class="links">` e altere nome, descrição, endereço e rótulo acessível. A logo fica em `logo-psicolentes.svg`.

## Publicar no GitHub Pages

O repositório público é `helneto12-del/psicolentes-br`, com estes arquivos na raiz da branch `main`. Em **Settings → Pages**, escolha **Deploy from a branch**, **main** e **/(root)**. O endereço é `https://helneto12-del.github.io/psicolentes-br/` após a publicação.

Este site não usa dependências, cookies ou serviços pagos.
